# Games

**Clasic games** made with JavaScript, HTML, and CSS. Can be played from PC or phone (web).

> [!IMPORTANT]  
> All games are open-source and free to use.  
> All games can be found on my [**game-hub**](https://danyilt.github.io/game-hub) page  
> source code of **game-hub**: [DanyilT/game-hub](https://github.com/DanyilT/game-hub)

---

## Repository Info

Games are based on [DanyilT/WebDev](https://github.com/DanyilT/WebDev) repo, in the [`page/games`](https://github.com/DanyilT/WebDev/tree/page/games) branch and hosted on Cloudflare Pages.

- **GitHub Repo Link**: [DanyilT/WebDev/tree/page/games](https://github.com/DanyilT/WebDev/tree/page/games)
- **Cloudflare Pages Link:** [danyilt-games.pages.dev](https://danyilt-games.pages.dev)

### Git clone

**Clone single branch (`page/games`) from repo: `DanyilT/WebDev`**

```bash
git clone https://github.com/DanyilT/WebDev.git --single-branch --branch page/games games
```
